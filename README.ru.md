AI Skills — коллекция переносимых пакетов инструкций для AI-агентов. Каждый skill
превращает сложную модель принятия решений в сфокусированный и проверяемый процесс
с явными границами применения.

Коллекция развивает три направления:

- **Метакогнитивный контроль** — проверка цели, доказательств, неопределённости и
  фактического завершения задачи.
- **Биологические принципы в архитектуре систем** — перевод биологических механизмов
  в проверяемые инженерные приёмы с обозначением границ аналогии.
- **Десятимерная инженерия** — оценка решений через взаимодействующие измерения
  качества вместо оптимизации одного свойства.

## Быстрый старт

Выберите skill из [каталога](#каталог-skills), прочитайте его `SKILL.md` и скопируйте
всю папку skill в каталог, поддерживаемый вашей AI-средой.

```text
skills/<skill-name>/
├── SKILL.md
└── references/       # только если нужны дополнительные материалы
```

После установки укажите имя skill в запросе или используйте автоматическое
обнаружение по `description`, если оно поддерживается вашей средой.

> [!IMPORTANT]
> Skill содержит инструкции и помогает принимать решения. Он сам по себе не даёт
> разрешения менять файлы, использовать credentials, обращаться к внешним сервисам,
> публиковать изменения или выполнять разрушительные действия.

### Десятимерная инженерия

| Skill | Назначение |
| --- | --- |
| [Ten-Dimensional Review](skills/ten-dimensional-review/SKILL.md) | Анализ системного решения через цель, контекст, информацию, структуру, поведение, время, ресурсы, отказы, доверие и развитие. |

контракт качества к разработке и code review.

## Принципы коллекции

- Точное назначение и условия применения каждого skill.
- Короткий `SKILL.md` и загрузка дополнительных материалов только при необходимости.
- Разделение предложенной проверки и фактически полученного результата.
- Сохранение границ пользовательских разрешений.
- Выбор минимально достаточного процесса и изменения.
- Самостоятельная, переносимая и проверяемая структура каждого skill.

## Добавление skill

Создайте `skills/<skill-name>/SKILL.md`, используя имя из строчных букв и дефисов:

```yaml
---
name: my-skill
description: Опишите, что делает skill и когда агент должен его применять.
---
```

Добавляйте `references/`, `scripts/` и `assets/` только при практической необходимости.
Проверка коллекции:

```bash
python scripts/validate_skills.py
```

Полные правила находятся в [CONTRIBUTING.md](CONTRIBUTING.md).

## Статус проекта

Коллекция развивается, а опубликованные skills являются начальными версиями.
Структурная проверка подтверждает упаковку и локальные ссылки, но не доказывает
эффективность на всех моделях, задачах и AI-средах.
